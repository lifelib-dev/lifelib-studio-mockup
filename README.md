# lifelib Studio — UI mockup

A static UI draft of lifelib Studio, an actuarial modelling environment built on
[modelx](https://github.com/fumitoh/modelx) and [lifelib](https://lifelib.io).
Figures shown come from lifelib's BasicTerm_S sample model.

View it at https://fumitoh.github.io/lifelib-studio-mockup/
